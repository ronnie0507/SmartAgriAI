# AgriSmart AI

An AI-assisted agricultural decision support system that helps farmers make
data-driven crop selection, crop rotation, irrigation, and land allocation decisions.

## Core Features
- Soil-based crop suitability analysis
- Weather-aware crop recommendations
- Real-time soil moisture monitoring using ESP32
- Groundwater and water availability monitoring
- Crop rotation recommendations
- Yield prediction
- Multi-crop land allocation optimization
- Next-season crop planning

## Technology Stack
- Frontend: React and Tailwind CSS
- Backend: Python and FastAPI
- Machine Learning: Scikit-learn and XGBoost
- Database: MongoDB
- IoT: ESP32 and soil sensors
- Optimization: Google OR-Tools

## Project Structure
- frontend/: Web application
- backend/: APIs and business logic
- ml/: Machine learning models
- iot/: Sensor firmware and simulation
- datasets/: Project datasets
- documentation/: Technical documentation
